# TJU 高级语言程序设计 · 第 03 模块作业

天津大学《高级语言程序设计》第 03 模块「结构化程序设计基础」的编程作业，包含 **顺序 / 选择 / 循环 / 输入错误处理** 四个专题，每题按课程要求给出 **C 与 C++ 两种实现**。

工程为 Visual Studio 解决方案 `高程作业.slnx`，每个题目对应一个独立的 `.vcxproj`。

> 课程约束贯穿全程：只允许一个 `main`，只允许白名单头文件与基本类型，**不允许**函数、数组、结构体、类、`string`、`goto` 等后续知识点，违规该题计 0 分。

## 环境与运行

| 项 | 说明 |
| --- | --- |
| 编译器 | Visual Studio 2026 / gcc（小熊猫 Dev-C++） |
| 运行方式 | VS 用 **Ctrl+F5**（不要 F5 调试）；gcc 用 **F11** |
| 硬性要求 | 两个编译器下均需 **0 errors, 0 warnings** |
| C 方式 | 文件必须是 `.c` 后缀，**不允许**用 `.cpp` 写完改名为 `.c` |
| C++ 方式 | 除明确要求外**不允许**使用 `scanf/printf` |
| 源文件编码 | GBK（VS 中文环境默认）。GitHub 网页直接预览源码可能显示乱码，VS / Dev-C++ 打开正常 |

## 代码规范（格式分占 10%）

1. **首行必须是** `/* 学号 班级 姓名 */` —— 首行错误扣 10 分。
2. 以 **4 个空格**为缩进单位，每层比上层多缩进 4 格。
3. 左大括号跟在语句后或另起一行均可，右大括号单独一行。
4. 单语句也可省略大括号，但必须另起一行；空语句的 `;` 另起一行。
5. `switch` 中 `case` 比 `switch` 缩进 4 格且单独成行（VS2026 需开启「缩进 case 标签」）。
6. 适当加入注释与空行。

**常见扣分**：格式错误 -10、首行错 -10、任一编译器 warning -50、error / 违规使用禁用知识 -100、**打表输出直接扣期末总分 20 分**。
